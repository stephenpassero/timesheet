# Timesheet

A simple weekly timesheet. Hours are saved in your browser's localStorage (key `timesheet:v1`), so data stays on the device and is not shared between devices.

Live: https://stephenpassero.github.io/timesheet/

Installable as a PWA (works offline once loaded).

Icon: [Material Symbols](https://fonts.google.com/icons) `schedule` (Apache 2.0).
